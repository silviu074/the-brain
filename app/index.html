FILES where Claude keeps things
Everything Claude Code knows about you lives in one folder: .claude in your user folder, plus a few files inside each project.
1 · Inside .claude
CLAUDE.md
Your global instructions. Loaded at the start of every session, in every project.
settings.json
Your settings: permissions, hooks, plugins, status line.
skills\
Your skills, one folder each with a SKILL.md.
agents\
Your subagents, one .md file each.
plugins\
Installed plugins and the marketplaces they came from.
projects\
One folder per project with a log file per conversation (HISTORY and LIVE read these) and Claude's auto memory.
2 · In each project
CLAUDE.md
Project instructions, loaded when Claude starts in that folder.
.claude\skills\ · .claude\agents\
Skills and agents that only exist in that project.
.claude\settings.json
Project settings that add to your global ones.
.mcp.json
Connectors (MCP servers) shared with everyone who opens the project.
The Brain shows the project you used most recently. Open Claude in another project, then press SYNC to switch.
