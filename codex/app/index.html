FILES where Codex keeps things
Everything Codex knows about you lives in one folder: .codex in your user folder (or CODEX_HOME if you set it).
1 · Inside .codex
config.toml
Your settings: model, approvals, sandbox, MCP servers, plugins.
AGENTS.md
Your global instructions. Read at the start of every session.
skills\
Your skills, one folder each with a SKILL.md. Skills in .agents\skills (in your user folder) count too.
sessions\
One log file per conversation, sorted by date. HISTORY and LIVE read these.
memories\
Facts saved from past sessions, when memories are on.
rules\
Rules that allow, ask about or block shell commands.
auth.json
Your login. The Brain never reads it.
2 · In each project
AGENTS.md
Project instructions, read when Codex starts in that folder.
.agents\skills\
Skills that only exist in that project.
.codex\config.toml
Project settings that override your global ones.
